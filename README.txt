TAMIZHAN UNAVAGAM WEBSITE
=========================

Files:
- index.html  : website content
- style.css   : design and responsive layout
- script.js   : mobile navigation and current year

HOW TO OPEN:
1. Extract the ZIP file.
2. Open the tamizhan_unavagam_website folder.
3. Double-click index.html (or right-click and open with Chrome/Edge).

NOTES:
- This is a frontend-only website.
- The Google Maps button opens a search for the supplied restaurant address.
- The sample menu categories are placeholders; replace them with the restaurant's
  actual dishes and prices before publishing.
- The hero photo is loaded from Unsplash, so internet access is needed for it.
